# 第 3 页：软件开发信息

> 来源：`docs/pages/raw/03-软件开发信息*.json`（2026-09-02 抓取，含 4 个联动场景）

## 字段清单

### 1. 软件分类
- 类型：下拉单选
- 选项：`应用软件` / `嵌入式软件` / `中间件` / `操作系统`
- 项目可推断性：✅ 绝大多数项目为"应用软件"，可根据项目性质判断

### 2. 软件说明
- 类型：单选
- 选项：
  - `原创`（value=ORIGINAL，默认选中）—— 独立开发的软件。
  - `修改（含翻译软件、合成软件）`（value=MODIFY）—— 对原有软件修改后形成的在功能或者性能方面有重要改进的软件。
- 项目可推断性：⚠️ 基于他人项目二次开发时选"修改"，需用户确认

### 3. 开发方式
- 类型：单选
- 选项（官方说明原文，含所需权属证明文件）：
  - `单独开发`（SINGLE，默认）—— 只依靠自身条件单独开发完成的软件。
  - `合作开发`（COOPERATE）—— 由两个以上的自然人、法人或者非法人组织合作开发的软件。**应提交证明著作权归属的书面合作开发合同或协议。**
  - `委托开发`（COMMISSION）—— 接受自然人、法人或者非法人组织委托开发的软件。**应提交证明著作权归属的书面委托开发合同或协议。**
  - `下达任务开发`（TASK）—— 由国家机关下达任务开发的软件。**应提交证明著作权归属的书面项目任务书或合同。**
- 项目可推断性：❌ 需用户提供；选非"单独开发"时在整改建议中提示准备权属证明文件

#### 3.1 是否多个著作权人共同享有软件著作权【条件字段】
- 触发条件：开发方式 ≠ 单独开发 时显示
- 类型：单选，`是`（value=0，默认）/ `否`（value=1）

### 4. 开发完成日期
- 类型：日期选择器
- 官方说明：指软件开发者将该软件全部固定在某种有形物体上的日期。
- 项目可推断性：✅ 可从 git 最后提交日期 / 发布日期推断；注意：不能晚于申请日

### 5. 发表状态
- 类型：单选
- 选项：`未发表`（0）—— 软件未公之于众。/ `已发表`（1，默认选中）—— 软件已公之于众。

#### 5.1 首次发表日期【条件字段】
- 触发条件：发表状态 = 已发表 时显示
- 类型：日期选择器
- 项目可推断性：✅ 可从首次公开发布日期（release/上线时间）推断；不能早于开发完成日期

#### 5.2 首次发表地点【条件字段】
- 触发条件：发表状态 = 已发表 时显示
- 类型：国家下拉（241 项，默认中国）+ 省/市二级级联（城市列表 AJAX 懒加载）

### 6. 著作权人【可重复表单组】
每条包含以下子字段（从实名认证信息带入，可编辑）：

| 子字段 | 类型 | 说明 |
|---|---|---|
| 国家 | 下拉 | 默认中国 |
| 地区 | 省/市级联 | |
| 身份类别 | 下拉 | 自然人 / 企业法人 / 机关法人 / 事业单位法人 / 社会团体法人 / 其他组织 / 其他 / 保密单位 |
| 姓名或名称 | 文本 | placeholder：姓名或名称，与身份证明文件保持一致 |
| 证件类型 | 下拉 | 居民身份证 / 军人身份证明（军/警官证、士兵证等）/ 户口本 / 其他有效证件 |
| 证件号码 | 文本 | |

- 组操作：每条可"编辑/保存"；开发方式为多著作权人时可"+添加著作权人"
- 项目可推断性：❌ 需用户提供（与实名认证一致）
