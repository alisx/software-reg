# 第 2 页：软件申请信息

> 来源：`docs/pages/raw/02-软件申请信息.json`（2026-09-02 抓取）
> 页面通用说明（官方原文）：本表适用于著作权人原始取得著作权，以及通过转让、继承或承受取得著作权的软件著作权人申请登记时填写。应当使用简体中文填写申请表中各事项，软件名称可以使用英文填写。外国人申请登记的，软件名称、著作权人、申请人事项仅限使用中文或英文填写。

## 字段清单

### 1. 权利取得方式
- 类型：单选
- 选项：
  - `原始取得`（value=ORIGINAL，默认选中）—— 自然人、法人或者非法人组织对其所开发的软件依法享有著作权。
  - `继受取得`（value=INHERITANCE）—— 通过受让、继承或者承受的方式取得著作权。
- 项目可推断性：⚠️ 默认"原始取得"；涉及接手他人项目时需用户确认

### 2. 软件全称
- 类型：文本输入，maxlength=100
- 官方说明：申请著作权登记的软件的全称。软件名称应简短明确，针对性强，申请材料中的软件名称应保持一致。
- 项目可推断性：⚠️ 可从项目名/产品名给建议，须用户定稿；命名惯例为"品牌+用途功能"，结尾通常带"系统/平台/软件"

### 3. 软件简称
- 类型：文本输入，maxlength=50
- 官方说明：对软件全称进行简化的名称。**如无简称请留空，不要填写"无"。**
- 项目可推断性：⚠️ 可留空

### 4. 版本号
- 类型：文本输入，maxlength=20
- 官方说明：版本号一般情况下按照"V数字"或"数字"的方式填写，例如：V1.0 或 2.0.1。
- 项目可推断性：✅ 可从 git tag / package.json / 发布记录推断

### 5. 权利范围
- 类型：单选
- 选项：`全部权利`（value=1，默认选中）/ `部分权利`（value=2）
- 项目可推断性：⚠️ 默认"全部权利"
