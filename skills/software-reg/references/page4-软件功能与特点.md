## 环境类字段（全部 ≤50 字，文本域）

|---|---|---|
| 开发的硬件环境 | 指开发登记软件的计算机硬件或专用设备。 | ✅ 通用填写（如"通用 PC 服务器"） |
| 运行的硬件环境 | 指运行登记软件的计算机硬件或专用设备。 | ✅ 从部署文档/Dockerfile 推断 |

| 该软件的运行平台 / 操作系统 | 指运行登记软件的操作系统及版本。 | ✅ 从部署配置推断 |
| 软件运行支撑环境 / 支持软件 | 指运行登记软件的支撑环境或支持软件。 | ✅ 从依赖清单推断（运行时、数据库、中间件） |

## 核心技术字段

### 7. 编程语言
- 类型：复选框组（21 项）+ "其他编程语言"文本域（≤120 字）
- 官方说明：指编写登记软件的编程语言，请从列表中选择开发登记软件用到的所有编程语言。
- 选项（value 与显示文本一致）：Assembly language、C、C#、C++、Delphi/Object Pascal、Go、HTML、Java、JavaScript、MATLAB、Objective-C、PHP、PL/SQL、Perl、Python、R、Ruby、SQL、Swift、Visual Basic、Visual Basic .Net
- 项目可推断性：✅ 从代码统计精确得出；不在列表中的语言（如 TypeScript、Kotlin、Rust）需写入"其他编程语言"

### 8. 源程序量
- 类型：文本输入（≤20 字，后缀单位"行"）
- 官方说明：指登记软件源程序的总行数或者总条数。
- 项目可推断性：✅ 精确统计（需明确统计口径：是否含空行/注释/第三方代码）

### 9. 开发目的
- 类型：文本域，≤50 字
- 官方说明：登记软件的创作目的。
- 项目可推断性：✅ 可从 README/项目定位归纳

### 10. 面向领域 / 行业
- 类型：文本域，≤50 字
- 官方说明：登记软件面向或适用的行业或领域。
- 项目可推断性：✅ 可从项目功能归纳

### 11. 软件的主要功能 ★
- 类型：文本域，**500–1300 字**（有字数下限，计数器显示 0/500~1300）
- 官方说明：全面、准确、概括地描述登记软件的主要功能。
- 项目可推断性：✅ 从 README、路由/菜单结构、模块划分归纳生成；**这是最重的生成任务**

### 12. 软件的技术特点 ★
- 类型：复选框组（15 项）+ 文本域（≤100 字）
- 官方说明：准确描述登记软件的技术特点。
- 选项：APP、游戏软件、教育软件、金融软件、医疗软件、地理信息软件、云计算软件、信息安全软件、大数据软件、人工智能软件、VR软件、5G软件、小程序、物联网软件、智慧城市软件
- 项目可推断性：✅ 从技术栈和功能判断勾选类别，文本部分概括架构特点

## 鉴别材料与附件

### 13. 程序鉴别材料 ★
- 类型：单选 + PDF 上传
- 选项：`一般交存`（NORMAL，默认）/ `例外交存`（EXCEPTION，选择后需选具体例外交存方式）
- 官方说明（原文）：
  - 提交登记软件源程序连续的前30页和连续的后30页（前、后各连续30页可以按开发时间排序，也可以按功能主次等自定义排序），每页不少于50行。若源程序整体不到60页，应提交全部源程序。
  - 程序和文档中出现的权利人署名、软件名称及软件版本号应当与其他申请文件相应内容一致。
- 上传提示：源程序前连续的30页和后连续的30页，PDF 格式
- 项目可推断性：✅ **agent 核心产出物**：从项目源码自动生成 60 页 PDF

### 14. 文档鉴别材料 ★
- 类型：单选（一般/例外交存）+ PDF 上传，可"+增加其他文档"上传多份
- 官方说明（原文）：提交登记软件的任何一种文档的连续的前30页和连续的后30页，每页不少于30行。若整个文档不到60页，应提交整个文档。文档是指用来描述程序的内容、组成、设计、功能规格、开发情况、测试结果及使用方法的文字资料和图表等，如程序设计说明书、流程图、用户手册等。
- 项目可推断性：✅ **agent 核心产出物**：生成用户手册/设计说明书草稿（需界面截图时提示用户补充）

### 15. 其他相关证明文件
- 类型：PDF 上传，可"+增加其他相关证明文件"上传多份
- 项目可推断性：❌ 如合作/委托开发的权属合同等，需用户准备；agent 负责提醒
